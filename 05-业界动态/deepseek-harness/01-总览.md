## 是什么

DeepSeek Harness（`dsh`）是 DeepSeek AI 开源的 **agent harness（智能体运行时）**：模型之外、让 agent 能理解环境、调用工具、在真实场景里持续工作的那一层。官方表述是 **Agent = Model + Harness**。

它不是新模型，也不是 DeepSeek API 的封装客户端。推理走你配置的模型端点；默认 DeepSeek 路由仍调 API，需要凭据。本地 Web UI 不等于本地推理。

核心口号：**Everything is a plugin**。模型适配器、工具、skills、会话、沙箱、存储、循环、调度、UI 全部是可替换插件，由 [Cordis](https://github.com/cordiverse/cordis) 内核负责挂载、卸载与依赖。

## 怎么跑

```sh
npx @deepseek-ai/dsh web
```

默认 Web UI：`http://127.0.0.1:3080`。源码安装用 `pnpm install && pnpm run build && pnpm dsh web`。另有 `headless` profile，一次性运行、不带服务器。

模型侧不绑定 DeepSeek：目录含 Anthropic、OpenAI、AWS Bedrock、Azure、Gemini，以及 OpenAI 兼容网关。

## 四种运行模式

同一套插件，按 preset 重组：

| 模式 | 是什么 |
|---|---|
| **Standard** | 完整 coding agent：文件编辑、shell、文件/网页搜索、skills、plan、goals、subagents、workflows |
| **Code** | Standard 的能力，工具通过 Code Mode SDK 暴露；模型写一段 TypeScript，一次编排多步工具调用 |
| **Minimal** | 只留持久 bash 与 `str_replace_editor`，用于在最少脚手架下评测模型 |
| **Creator** | Standard + 运行时自省、内存中试挂 Cordis 插件、编写自定义 preset。模型可对 live runtime 写 JS，信任级别等同 shell |

## 两条设计原则

1. **Everything is a plugin**：没有需要 fork 才能改的特权内核；换能力靠挂插件或改配置。
2. **Every run is traceable**：模型看见的一切写入仅追加的 session log。Trajectory 按来源查看；resume / fork / search / replay 都基于同一条事件流。
