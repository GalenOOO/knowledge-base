# 分镜脚本模板

> 本文档目的：多镜用的 brief + 对话模型提示词。单镜不要用本模板，一句话写清谁、在哪、一个动作、一个运镜即可，见 [`04-单镜.md`](./04-单镜.md)。从选题起的完整提示词链见 [`提示词/00-用法.md`](./提示词/00-用法.md)。

用法：复制「Brief 模板」填空 → 整段 brief 和「生成提示词」一起发给对话模型 → 输出粘进 `实践/01-分镜.md` → 用文末检查清单过一遍再去可灵。执行流程见 [`05-多镜.md`](./05-多镜.md)。

---

## Brief 模板

复制后填括号。不要在这里写完整故事。

```
# Brief

1. **镜头**：（单镜 / 多镜）—— 单镜请停，改走单镜流程
2. **是否锁形象**：（是 / 否）
3. **成片规格**：平台（ ）；时长（ ）秒；比例（9:16 / 16:9）
4. **主体**：（虚构角色或物品的一句外貌；不要未授权真人）
5. **本片镜数**：（每镜 5 秒；15 秒 = 3 镜）

补充：
- 场景：（同一条街 / 是否换景）
- 各镜动作按时间顺序写，必须能接上，例如：侧向走 → 停下转身看镜头 → 面对镜头说话
- 不要写互相打架的朝向（已面向镜头，就不能再「回头看镜头」）
```

## Brief 示例

多镜、锁形象、同一场景、朝向能接上：

```
# Brief

1. **镜头**：多镜
2. **是否锁形象**：是
3. **成片规格**：平台（横屏练习）；时长（15）秒；比例（16:9）
4. **主体**：虚构角色。25 岁东亚女性，短黑发齐耳，米色风衣，白色衬衫，神情冷静。不要真人。
5. **本片镜数**：3（每镜 5 秒）

补充：
- 场景：同一条雨夜霓虹街道，电影感
- 各镜动作：侧向沿街道走（正侧，不看镜头）→ 停下后转身看向镜头 → 面对镜头说话
```

不要写成「走向镜头、停下回头、中景说话」：第一镜已经面向镜头，第二镜无法再回头看镜头。

单镜示例（本模板到此为止，不要再往下贴生成提示词）：

```
# Brief

1. **镜头**：单镜
2. **是否锁形象**：否
3. **成片规格**：横屏；5 秒；16:9
4. **主体**：虚构角色。25 岁东亚女性，短黑发齐耳，米色风衣。
5. **本片镜数**：1

补充：雨夜霓虹街道，正侧缓步前行，中景侧面跟拍，电影感。
```

## 生成提示词

把上面填好的 brief 放在这段**之前**，一起发给对话模型。

```
根据上面的 brief，写一张可直接拿去可灵执行的分镜表。

把各镜当成同一空间里的连续走位，不要当成互不相关的提示词列表。
上一镜结束时人物的朝向，必须能接下一镜的动作。

约束：
- 若 brief 写的是单镜：不要出分镜表，只回复「请走单镜流程，用 04-单镜.md 的首帧元提示词」
- 只有 brief 里的主体，不要加配角、不要真人
- 视频镜头数按 brief：每镜 5 秒，每镜只做一件事（一个动作 + 一个运镜）
- 先给「外貌锁定句」：一句写死年龄感、发型、服装、体态；设定图提示词必须逐字包含这句。锁形象时，首帧生图提示词不复述这句，改写「保持与设定图相同的外貌与服装」；不锁形象时，首帧生图提示词仍逐字包含这句。视频提示词不复述这句、场景和景别，改写「保持与首帧相同」
- 若 **锁形象**：额外列出设定图清单（正面半身、45°半身、侧面全身），每张一条生图提示词。设定图提示词 = 外貌锁定句 + 明确角度（45°要写能看见两只眼；正侧要写 90°、只能看见一只眼）+ 干净浅色背景 + 均匀柔光 + 写实 + 无文字
- 每个视频镜头一行，列必须有：
  镜号 | 画面 | 动作 | 开始朝向 | 结束朝向 | 景别与运镜 | 比例 | 时长 | 用哪张图当首帧 | 生图提示词 | 视频提示词 | 负面
- 「生图提示词」是该镜首帧（动作开始时的静止画面）。不锁形象：外貌锁定句 + 该镜场景 + 开始朝向/姿态 + 写实 + 无文字。锁形象：「保持与设定图相同的外貌与服装」+ 该镜场景 + 开始朝向/姿态 + 写实 + 无文字。要碰到的东西写在运动路径上；姿态是尚未接触；景别能看见交互点。不要写运镜、不要写还没发生的动作、不要写已经发生的结果（水花、迈完的步）
- 「视频提示词」结构：「保持与首帧相同」+ 动作 + 运镜
- 负面默认：变形文字，多余手指，换脸，换装，主体消失
- 不要故事简介、不要旁白。只输出：1）外貌锁定句 2）设定图提示词（锁形象才有） 3）Markdown 表格
```

## 输出后检查

不通过就改 brief 重出，不要进可灵改戏。

- 锁定句在每条设定图提示词里逐字相同。锁形象：首帧生图提示词不复述锁定句；不锁形象：首帧生图提示词逐字含锁定句。视频提示词不复述锁定句、场景和景别
- 每镜一个动作、一个运镜
- 镜数 × 5 秒 ≈ 目标时长；比例全表相同
- **朝向能接**：第 N 镜结束朝向 = 第 N+1 镜开始朝向（或能靠该镜动作转过去）。禁止：面向镜头走来，下一镜再回头看镜头
- 首帧提示词是静止姿态，空间能接该镜动作；视频提示词才写运动
- 锁形象：设定图正 / 斜 / 侧三条，服装与锁定句一致
