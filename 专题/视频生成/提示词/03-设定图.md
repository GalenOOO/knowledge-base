# 3. 设定图提示词（角色、场景、道具）

> 本文档目的：从角色表、场景表写出设定图生图提示词。设定图用来建主体和当参考，不直接拿去出视频。

把 `实践/01-分镜.md` 的「外貌锁定句、角色表、场景表」放在这段**之前**（可附采用创意的风格与视觉锚点），一起发给对话模型。生成后下载到 `实践/02-设定图/`。锁形象步骤见 [`../03-锁形象与主体.md`](../03-锁形象与主体.md)。

设定图 ≠ 首帧。设定图：干净背景、多角度、无剧情。首帧：有场景、有景别，见 [`04-首尾帧.md`](./04-首尾帧.md)。

---

```
你是影视美术指导，为 AI 图生视频准备参考图提示词。根据上面的外貌锁定句、角色表、场景表写生图提示词。

只写设定图。不要写首帧、不要写视频提示词、不要改剧情。

锁形象靠参考图，不靠在提示词里反复形容「同一张脸」。角色三张图的外貌锁定句必须逐字相同。

## 角色设定图

每个角色三张，按这个顺序，先出正面：

1. 正面半身
2. 45° 半身：相机在人物左前方 45 度，能看见两只眼睛和完整鼻子，不是正侧
3. 侧面全身：严格 90 度正左侧，只能看见一只左眼，右眼完全不可见，从头顶到鞋

结构（一条，不要换行成诗）：

外貌锁定句 + 明确角度 + 干净浅色背景 + 均匀柔光 + 写实 + 无文字

禁止写进角色设定图：场景、动作、运镜、剧情、表情表演（神情用锁定句里已有的一个词，如「神情冷静」）。

不合格角度要在该条「负面」里写：45° 的负面含「正侧面、90度、只能看见一只眼睛」；侧面全身的负面含「四分之三侧面、45度、能看见两只眼睛、半身、特写」。

先定正面；提示里注明：后两张生成时把正面图当角色参考。

## 道具设定图

采用创意或分镜里反复出现的关键道具才出。三张：正面、侧面、细节（Logo、材质、缺口等识别点）。

结构：物件外形材质颜色 + 角度 + 干净浅色背景 + 均匀柔光 + 写实 + 无文字

有实拍则注明「优先用实拍，本提示词作补全」。

## 场景板

每个场景ID 一张空场景，无人、无角色、无文字招牌变形。比例与成片相同（写在「生成参数」，不写进提示词正文）。

结构：

地点 + 时间 + 光线（主光方向、软硬、色温、环境光颜色） + 可识别的空间层次（前景/中景/背景各一件实在的东西） + 写实 + 无人物 + 无文字

场景板是这一场的空间和光线锚点。不要浅景深把背景融成色斑。不要人物。

同片所有场景板加同一句风格锁定（色温与写实程度逐字相同）。

## 生成参数（每条提示词旁标注，不写进提示词）

- 角色设定图：1:1 或 3:4；连出 2–4 张只留一张
- 场景板：与成片相同（9:16 或 16:9）
- 风格：写实；不要水墨/插画滤镜

## 输出格式（不要开场白）

### 1）风格锁定句

一句。场景板必须逐字包含。

### 2）角色

每个角色：

- 外貌锁定句（逐字）
- 正面半身：提示词 + 负面 + 生成参数
- 45° 半身：提示词 + 负面 + 生成参数 +「挂正面当角色参考」
- 侧面全身：提示词 + 负面 + 生成参数 +「挂正面当角色参考」

### 3）道具

无则写「无」。有则同上，三条提示词。

### 4）场景板

每个场景ID：提示词 + 负面（人物、文字、变形招牌）+ 生成参数

## 输出前自检

- 同一角色三张锁定句逐字相同
- 角色提示词不含场景
- 场景板不含人物
- 45° 写了两只眼；正侧写了 90°、一只眼
- 光线具体，没有单独用「电影感」充数
```

## 输出后检查

不过就重出本步。出图后再验图，不合格重出该张，不进首帧。

- 锁定句在角色三张里逐字相同
- 角色图干净背景；场景板无人
- 角度合格
- 无字、无换装

出图不合格：脸崩、换装、出字、背景杂、角度不对、场景板里出现人。
