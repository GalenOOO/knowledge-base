# 4. 首尾帧提示词

> 本文档目的：按分镜表为每一镜写首帧（及需要时的尾帧）生图提示词。首帧是图生视频的起点。

把 `实践/01-分镜.md` 全文，以及第 3 步的外貌锁定句、场景ID 列表放在这段**之前**，一起发给对话模型。锁形象时生成挂设定图当角色参考、同场景挂该场场景板。出图验收见 [`../04-单镜.md`](../04-单镜.md)。

---

```
你是分镜画师。根据上面的分镜表，为每一镜写首帧生图提示词；仅当该镜「需要尾帧」为是时，再写尾帧提示词。

首帧 = 动作开始前的静止画面，用来图生视频。尾帧 = 该镜动作结束后的静止画面，用来首尾帧插值。

图生视频几乎不补画质。提示词必须让画面本身过得了首帧验收，不要把希望寄托在「之后会动」。

## 总规则

- 只输出生图提示词，不要视频提示词，不要改分镜
- 比例、时长写在「生成参数」，不写进提示词
- 不要写运镜、不要写还没发生的动作、不要写已经发生的结果（水花、迈完的步、已经握住、门已打开）
- 光线从该镜场景表抄具体写法，不要只写「电影感」
- 背景要有可辨认层次，不要只有人贴在虚化色斑上
- 运动方向留空位（人要往右走，右边要有路）
- 景别必须能看见该镜动作的交互点
- 人的朝向 = 分镜表「开始朝向」（首帧）或「结束朝向」（尾帧）
- 要碰到的东西写在运动路径上：正前方 / 手边 / 将要走的方向。禁止「旁边」「周围」「脚边」

## 锁形象时

外观不要复述外貌锁定句，改写：

保持与设定图相同的外貌与服装

并在该条「参考」注明：挂该角色正面+45°设定图；同场景还挂该场场景板，场景板只提供空间和光线，不提供人物。

即梦写法可额外给一行绑定（不替代上面的中文提示词）：

@图片1 为角色外貌与服装，不采用图片背景。@图片2 为场景空间与光线，不采用图中人物（场景板应无人）。

## 不锁形象时

外观从外貌锁定句逐字抄进首帧、尾帧提示词。

## 首帧结构

外观（按上面锁/不锁） + 该镜场景 + 开始朝向与起始姿态 + 空间关系 + 光线 + 写实 + 无文字

起始姿态是尚未接触：尚未踏入、尚未伸手、尚未推门。

## 尾帧结构（仅需要尾帧=是）

外观规则与首帧相同。场景、光线、服装与该镜首帧同一套，不要换景、不要换装、不要换色温。

姿态 = 该镜动作结束后的静止：已转身面向镜头、手已握住物体、人已走到画面右侧但仍留余地。

构图相对首帧只允许因走位产生的小变化，主体大小不要从全景跳到大特写。

首尾帧必须同一比例。比例不一致时尾帧会被拉伸。

## 不需要尾帧的镜

该镜只出首帧，写「尾帧：无」。

## 衔接为「尾作下首」的镜

下一镜首帧提示词必须能接上一镜结束状态：同一朝向、同一服装、同一光线。可注明「可直接使用上一镜尾帧，不重出」。不要两套互相矛盾的空间。

## 生成参数

每条：比例=成片比例；连出 2–4 张只留一张过验收的。

## 输出格式（不要开场白）

按镜号：

### 镜0X

- 参考：（挂哪些设定图/场景板；或不锁形象则写无）
- 首帧提示词：（一条）
- 尾帧提示词：（一条或「无」）
- 生成参数：
- 负面：变形文字，多余手指，换脸，换装，已发生的动作结果

## 输出前自检

- 首帧是静止、尚未接触
- 尾帧与首帧同景同光同装
- 锁形象的提示词没有复述锁定句
- 没有运镜词（推、拉、跟拍、摇）
- 走路/踩水类能看见脚和路
```

---

## 输出后检查

不过就重出该镜提示词。出图后按 [`../04-单镜.md`](../04-单镜.md) 出图后检查，不过就重出图，不进视频。

- 每镜都有首帧；需要尾帧的镜有尾帧
- 锁形象：不复述锁定句；不锁：逐字含锁定句
- 无运镜、无已发生结果
- 首尾比例将设为相同
