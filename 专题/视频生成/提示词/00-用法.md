# 提示词链用法

> 本文档目的：用对话模型按固定顺序产出可执行素材，从选题接到视频提示词。

每步只干一件事。上一步的输出整段贴进下一步，不要靠聊天记忆。

操作文档：锁形象 [`../03-锁形象与主体.md`](../03-锁形象与主体.md)，单镜 [`../04-单镜.md`](../04-单镜.md)，多镜 [`../05-多镜.md`](../05-多镜.md)。已有 brief、只出分镜表时仍可用 [`../06-分镜脚本模板.md`](../06-分镜脚本模板.md)。

## 顺序

| 步 | 文件 | 对话模型产出 | 落到 |
|---|---|---|---|
| 1 | [`01-选题.md`](./01-选题.md) | 三个创意 + 一张采用创意卡 | `实践/00-brief.md` |
| 2 | [`02-剧本分镜.md`](./02-剧本分镜.md) | 剧本节拍 + 角色/场景表 + 分镜表 | `实践/01-分镜.md` |
| 3 | [`03-设定图.md`](./03-设定图.md) | 角色/场景/道具的生图提示词 | `实践/02-设定图/` |
| 4 | [`04-首尾帧.md`](./04-首尾帧.md) | 每镜首帧、需要时尾帧的生图提示词 | `实践/03-首帧/` |
| 5 | [`05-视频.md`](./05-视频.md) | 每镜图生视频提示词 | `实践/04-视频/` |

3–5 的输出拿去生图/生视频，不拿去再写故事。某步检查清单不过：改那一步的输入重出，不要在可灵里改戏。

## 用户输入

复制后填括号，和 [`01-选题.md`](./01-选题.md) 的提示词一起发给对话模型。

```
# 输入

- 题材意向：（一句话，可空，空则由模型给三个方向）
- 平台：（抖音 / 红果 / 横屏练习 / 其他）
- 时长：（ ）秒
- 比例：（9:16 / 16:9）
- 锁形象：（是 / 否）
- 角色限制：（默认虚构，最多 2 人；不要未授权真人）
- 禁忌：（可不填）
- 风格：（写实 / 其他一句；默认写实）
```

默认：横屏练习、15 秒、16:9、锁形象、写实、1 个主角。

时长 ≤ 8 秒且只有一个动作 → 后续按单镜；否则按多镜，镜数 ≈ 时长 ÷ 5。
