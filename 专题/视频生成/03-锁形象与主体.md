# 锁形象与主体

> 本文档目的：说明如何用参考图/主体让人物、角色、物品在多次生成中保持外观一致。单镜与多镜通用。

锁形象靠 **参考绑定**，不靠把外貌写进提示词。文字锁不住脸和产品结构。

## 各家对应

| 工具 | 做法 |
|---|---|
| **可灵 3.0** | 「主体/元素库」：2–4 张多角度图，或 3–8 秒参考视频；生成时开 **绑定主体**。Omni 可同时参考更多主体 |
| **即梦 Seedance 2.0** | 「全能参考」，提示词写 `@图片1 保留面部和服装` |
| **Runway Gen-4.5** | References，提示词用 `@角色名` |
| **Veo 3.1** | Ingredients to Video，最多约 3 张参考图（主体/场景/风格） |

## 设定图与首帧

- **设定图**：这个人/物长什么样。干净背景，多角度。用来建主体，以及出首帧时当角色参考。
- **首帧**：这一镜开始时的画面。有场景、有景别。用来图生视频。

设定图不直接拿去出视频。

## 资产

- 人物/角色：正面半身、45° 半身、侧面全身；服装固定。45°：能看见两只眼睛。正侧：90°，只能看见一只眼睛。
- 物品/产品：正面、侧面、背面、细节（Logo、材质）。有实拍用实拍。
- 真人脸作参考，商业用途需要本人授权。

## 生成设定图

文生图，不进视频。外观锁定句三张（或多张）逐字相同。提示词不含 brief 里的场景、动作、运镜。

结构：`外观锁定句 + 明确角度 + 干净浅色背景 + 均匀柔光 + 写实 + 无文字`

例（正面半身）：`一位25岁东亚女性，短黑发齐耳，米色风衣，白色衬衫，神情冷静，体态纤长，正面半身，干净浅色背景，均匀柔光，写实，无文字`

1. 从 brief 的「主体」写出一句外观锁定句。
2. 按「资产」逐张生图。每张连出 2–4 张，只留一张。
3. 先定正面；后两张挂这张正面当角色参考。
4. 下载到 `实践/02-设定图/`。

不合格：脸崩、换装、出字、背景杂、角度不对。

## 可灵：建主体并绑定

入口在创作台侧栏或顶栏：**主体库 / 主体 / 元素**。没有独立菜单时：视频生成 → 图生视频 →「绑定主体 / @角色」里新建。

1. 创建主体 → 类型选 **角色**（或道具）→ **用图创建**（不要选数字人、不要一上来就用视频）。
2. 名称用短名。上传设定图；正面必须有。
3. 描述填外观锁定句。等状态变成可用。
4. 图生视频时打开 **绑定主体**，选这个主体。

即梦：全能参考上传图，提示词 `@图片1 为角色外观`。

之后设定图提示词用外观锁定句。出首帧时挂设定图，提示词写「保持与设定图相同的外貌与服装」，不复述锁定句；场景、姿态、空间关系仍要写。图生视频写「保持与首帧相同」，只写动作、运镜。

## 人物与物品

- **人物/角色**：可灵主体绑定；声音一致时用 Omni 视频建主体（提取外观和音色）。
- **物品/产品**：用实拍图当参考。即梦对 Logo、包装文字更稳。产品变形时用实拍当首帧，并写「保持产品外观、Logo 不变形」。

绑定后，单段 10–15 秒脸通常能稳住。极端侧脸、极暗、角色很小、大动作时仍会漂。可缩短镜头、减小运动、补参考角度。
