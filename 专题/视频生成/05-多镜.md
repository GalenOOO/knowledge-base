# 多镜视频

> 本文档目的：多条短镜头拼成片的流程与步骤。分镜用 [`06-分镜脚本模板.md`](./06-分镜脚本模板.md)，主体见 [`03-锁形象与主体.md`](./03-锁形象与主体.md)。

多镜：每次生成 5–15 秒素材，再剪成片。素材放 [`实践/`](./实践/)：

```
实践/
├── 00-brief.md
├── 01-分镜.md
├── 02-设定图/      # 锁形象时使用
├── 03-首帧/
├── 04-视频/
└── 05-成片/
```

文件名带镜号：`镜01-首帧.png`、`镜01-v1.mp4`。重试用 `v2`，不要覆盖。

## 步骤（可灵）

1. 把 brief 写在 `实践/00-brief.md`，字段用 [`06-分镜脚本模板.md`](./06-分镜脚本模板.md)。镜数按每镜约 5 秒反推；各镜动作按时间顺序，记录开始/结束朝向。
2. 对话模型出分镜表，粘进 `实践/01-分镜.md`，用模板文末清单过一遍。改剧情只改 brief 重出表。
3. 打开 [klingai.com/app](https://klingai.com/app)。图片模型全片同一个；不锁形象用视频 3.0，锁形象用 Omni（没有 Omni 就用 3.0，但必须开绑定）。比例与分镜表一致；每镜时长 5 秒；声音先关。
4. **图片生成**。每张连出 2–4 张，只留一张。
   - 不锁形象：按表为每镜出一张首帧，下载到 `03-首帧/`。
   - 锁形象：按 [`03-锁形象与主体.md`](./03-锁形象与主体.md) 出设定图、建主体；再按表格「生图提示词」出每镜首帧（挂设定图当角色参考；同场景用镜 01 首帧对齐背景）。
   - 首帧不合格：脸崩、多指、文字、主体太小、比例不对。不要拿去图生视频。
5. **视频生成 → 图生视频**。不要文生，不要用可灵「智能分镜」一次出成片。按分镜表一镜一次：上传该镜首帧；锁形象则绑定同一主体；复制表格「视频提示词」，不要删锁定句、不要临时加剧情。能用则下载为 `镜01-v1.mp4`。同镜最多 3 次；三次不过就拆镜或改分镜表。
6. 剪映按镜号硬切排上时间线，再加字幕、BGM、封面。导出到 `05-成片/`。

能用：动作完整、首帧主体还在。锁形象还要脸和衣服与设定图是同一个人。

一次只改一件事：脸漂 → 确认绑定、首帧、动作改小；动作乱 → 拆镜或去掉复杂运镜；主体太小 → 首帧改中近景；出字 → 负面加「不要文字」；风格跳 → 风格句逐字相同。

角色不变的下一片：主体继续用，只换新场景首帧。

## 跨镜头衔接

- 上一镜结束朝向接下一镜动作（面向镜头走来，无法再回头看镜头）。
- 上一镜最后一帧可作为下一镜首帧（frame chaining）。
- 光线、服装、色温不要镜间大跳。同场景以第一镜首帧为场景锚点。
