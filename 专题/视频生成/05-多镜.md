# 多镜视频

> 本文档目的：多条短镜头拼成片的流程与步骤。工具见 [`02-可灵与即梦.md`](./02-可灵与即梦.md)，分镜用 [`06-分镜脚本模板.md`](./06-分镜脚本模板.md)，主体见 [`03-锁形象与主体.md`](./03-锁形象与主体.md)。

多镜：每次生成 5–15 秒素材，再剪成片。每镜仍是「一张首帧 → 图生视频」，提示词拆法见 [`04-单镜.md`](./04-单镜.md)。素材放 [`实践/`](./实践/)：

```
实践/
├── 00-brief.md
├── 01-分镜.md
├── 02-设定图/      # 锁形象时使用
├── 03-首帧/
├── 04-视频/
└── 05-成片/
```

文件名带镜号：`镜01-首帧.png`、`镜01-v1.mp4`。重试用 `v2`。

## 步骤

1. 把 brief 写在 `实践/00-brief.md`，字段用 [`06-分镜脚本模板.md`](./06-分镜脚本模板.md)。镜数按每镜约 5 秒反推；各镜动作按时间顺序，记录开始/结束朝向。
2. 对话模型出分镜表，粘进 `实践/01-分镜.md`，用模板文末清单过一遍。改剧情只改 brief 重出表。
3. 锁形象：按 [`03-锁形象与主体.md`](./03-锁形象与主体.md) 出设定图、建主体，等状态可用。
4. 按分镜表逐镜生图首帧，比例与表一致。锁形象时挂设定图当角色参考；同场景用镜 01 首帧对齐背景。下载到 `03-首帧/`。出图后验收，不过就重出该镜。
5. 逐镜图生视频：上传该镜首帧；锁形象则绑定同一主体；用表格「视频提示词」。能用则下载为 `镜01-v1.mp4`。同镜最多 3 次；三次不过就拆镜或改分镜表。
6. 按镜号排上时间线，再加字幕、BGM、封面。导出到 `05-成片/`。

能用：动作完整、首帧主体还在。锁形象还要脸和衣服与设定图是同一个人。

一次只改一件事：脸漂 → 确认绑定、首帧、动作改小；动作乱 → 拆镜或去掉复杂运镜；主体太小 → 首帧改中近景；出字 → 负面加「不要文字」；风格跳 → 风格句逐字相同。

角色不变的下一片：主体继续用，只换新场景首帧。

## 跨镜头衔接

- 上一镜结束朝向接下一镜动作（面向镜头走来，无法再回头看镜头）。
- 上一镜最后一帧可作为下一镜首帧（frame chaining）。
- 光线、服装、色温镜间保持一致。同场景以第一镜首帧为场景锚点。

## 出图后检查

每镜先按 [`04-单镜.md`](./04-单镜.md) 文末三条验收。跨镜另看：

- 第 N 镜结束朝向接得上第 N+1 镜开始朝向
- 同场景时，背景与镜 01 首帧是同一条街
