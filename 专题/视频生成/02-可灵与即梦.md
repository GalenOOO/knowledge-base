# 可灵 3.0 与即梦 Seedance 2.0

> 本文档目的：记录两家国内主力工具的出品方、模型名称与基本用法。信息截至 2026-08。

产品名和模型名不是一回事：可灵是快手的产品，模型是可灵 3.0 系列；即梦是字节的产品，视频模型是 Seedance 2.0。

出片步骤见 [`04-单镜.md`](./04-单镜.md)、[`05-多镜.md`](./05-多镜.md)；主体见 [`03-锁形象与主体.md`](./03-锁形象与主体.md)。

## 可灵 3.0

**公司**：快手科技。产品名 **可灵 AI**（海外品牌 Kling）。

**模型**：可灵自研 3.0 系列，不是套别人的模型。2026 年 2 月上线，视频主要两档：

| 模型 | 从哪升级 | 干什么 |
|---|---|---|
| **可灵视频 3.0** | 2.6 | 文生/图生/首尾帧、分镜、音画同步 |
| **可灵视频 3.0 Omni** | O1 | 多模态参考、视频建角色、音色绑定、更强一致性 |

另有图片模型：可灵图片 3.0 / 3.0 Omni。做视频时在界面选 **视频 3.0** 或 **3.0 Omni**。锁形象用 Omni。

**怎么用**

1. 打开 [kling.ai](https://kling.ai) 或 [klingai.com/app](https://klingai.com/app)（国内可直开，也可用 App「可灵AI」）。
2. 微信 / 手机号 / 快手账号登录。消耗「灵感值」。
3. 进 **视频生成**，选模型（不锁形象用 3.0，锁形象用 Omni）。
4. 单镜 / 多镜出片见 [`04-单镜.md`](./04-单镜.md)、[`05-多镜.md`](./05-多镜.md)。
5. 锁形象：先到 **主体库** 建主体，生成时打开 **绑定主体**。见 [`03-锁形象与主体.md`](./03-锁形象与主体.md)。不是数字人。
6. 开发者可走可灵开放平台 API。

## 即梦 Seedance 2.0

**公司**：字节跳动。产品名 **即梦 AI**（前身 Dreamina，挂在剪映域名下）。

**模型**：**Seedance 2.0**，字节 Seed 团队的视频生成模型。即梦是装这个模型的创作台。同一模型还出现在豆包 App、火山方舟（API 名常见为 `Doubao-Seedance-2.0` / `seedance-2.0`）。

即梦里的生图模型是另一条线：**Seedream**，不要和 Seedance 混。

**怎么用**

1. 打开 [jimeng.jianying.com](https://jimeng.jianying.com)（网页版最全；也可下 App「即梦」）。
2. 手机号 / 抖音 / 微信登录。
3. 进 **视频生成**，模型手动切到 **Seedance 2.0**（默认可能不是它）。
4. **单镜**：走 **首尾帧**（一张首帧图 + 提示词就够）。
5. **锁形象 / 多参考**：走 **全能参考**，提示词用 `@图片1 保留面部和服装` 指定每份素材干什么。
6. 企业/程序调用走火山方舟 API。

Seedance 2.0 曾因滥用暂停过「真人脸作主体参考」。用真人照片前，先看当前界面是否还允许。

## 对照

| | 可灵 3.0 | 即梦 Seedance 2.0 |
|---|---|---|
| 公司 | 快手 | 字节跳动 |
| 产品 | 可灵 AI | 即梦 AI |
| 视频模型 | 可灵视频 3.0 / 3.0 Omni | Seedance 2.0 |
| 入口 | kling.ai / klingai.com/app | jimeng.jianying.com |
