# 单镜视频

> 本文档目的：一次生成 5–15 秒、不再分镜拼接的入口、步骤与提示词。工具见 [`02-可灵与即梦.md`](./02-可灵与即梦.md)，主体见 [`03-锁形象与主体.md`](./03-锁形象与主体.md)。

单镜：一条生成即成片。素材放 [`实践/`](./实践/)，可只用 `03-首帧/` 和 `04-视频/`。

## 三种入口

1. **文生视频（T2V）**：一句话出片。适合氛围、风景、抽象镜头。人物脸、产品细节容易糊。
2. **图生视频（I2V）**：先有一张关键帧，再让它动。人物和产品比纯文生稳。
3. **首尾帧**：给起点图和终点图，模型补中间。适合转场、走位、产品旋转。

## 步骤

1. 写 brief：主体、场景、一个动作、一个运镜、时长、比例。

   ```
   主体：（人物 / 物品 / 场景的一句外观）
   场景：（在哪）
   动作：（一件事）
   运镜：（景别 + 运动）
   时长：（ ）秒
   比例：（9:16 / 16:9）
   锁形象：（是 / 否）
   ```

   示例：

   ```
   主体：25 岁东亚女性，短黑发齐耳，米色风衣，白色衬衫，神情冷静，体态纤长
   场景：雨夜霓虹街道，湿沥青倒映红蓝招牌，正前方路面有一滩积水，与行走方向同一条线
   动作：正侧大步冲进积水奔跑，风衣被风整片掀起，积水向两侧炸开
   运镜：中景侧面快速跟拍，略低机位，浅景深
   时长：5 秒
   比例：16:9
   锁形象：是
   ```
2. 锁形象：按 [`03-锁形象与主体.md`](./03-锁形象与主体.md) 出设定图、建主体，等状态可用。
3. 生图首帧，比例与 brief 相同。提示词写静止画面，空间能接第 1 步的动作。锁形象时挂设定图当角色参考。连出 2–4 张，只留一张过验收的。下载到 `实践/03-首帧/`。出图后用文末清单验收，不过就重出，不进图生视频。
4. 图生视频，上传首帧。锁形象则绑定参考。时长与 brief 一致。先 720p 出 2–3 条，过文末「能留」再用同一套参数出 1080p / 4K。
5. 下载到 `实践/04-视频/`。需要字幕或 BGM 时再进剪辑：在动作上剪，统一色温，补环境声。

## 提示词

brief 不是提示词。时长、比例只当生成参数。有图就不复述图里已有的：设定图管外观，首帧管场景和姿态，视频管动作和运镜。

| Brief | 首帧提示词 | 视频提示词 |
|---|---|---|
| 主体、场景 | 不锁：外观 + 场景；锁：保持与设定图相同 + 场景 | 「保持与首帧相同」 |
| 一个动作 | 开始那一瞬的静止姿态；要碰到的东西在运动路径上 | 这个动作怎么发生 |
| 一个运镜 | 景别、机位（静止） | 镜头怎么动 |
| 时长、比例 | 生图设比例 | 图生视频设时长和同一比例 |

**首帧（不锁形象）**：`主体 + 场景 + 起始姿态 + 光线/风格`

例：`一位25岁东亚女性，短黑发齐耳，米色风衣，白色衬衫，神情冷静，体态纤长，雨夜霓虹街道，湿沥青倒映红蓝招牌，正侧，能看见脚的中景，人物站在街道上，正前方路面有一滩积水与行走方向同一条线，前脚停在积水边缘尚未踏入，静止，无水花，略低机位，浅景深，电影感，不要变形文字。`

**首帧（锁形象）**：`保持与设定图相同的外貌与服装 + 场景 + 起始姿态 + 光线/风格`

例：`保持与设定图相同的外貌与服装，雨夜霓虹街道，湿沥青倒映红蓝招牌，正侧，能看见脚的中景，人物站在街道上，正前方路面有一滩积水与行走方向同一条线，前脚停在积水边缘尚未踏入，静止，无水花，略低机位，浅景深，电影感，不要变形文字。`

**视频**：`保持与首帧相同 + 动作 + 运镜`

例：`保持与首帧相同，正侧大步冲进积水奔跑，风衣被风整片掀起，积水向两侧炸开，侧面快速跟拍。`

一条视频提示词对应一个动作、一个运镜。衣摆、头发、水花等次级运动最多再写一件。动作、运镜、环境效果同时写猛，画面会糊、边缘会扭。上面这条示例已经超载，练习用；要稳就改成「正侧迈一步踏进积水，水花向两侧溅开，侧面跟拍」。

## 首帧元提示词

把 brief 放在这段**之前**，发给对话模型，用输出去生图。

```
根据上面的 brief，写一条可直接拿去生图的首帧提示词。

首帧是动作开始前的静止画面，用来图生视频。图里的空间必须能接 brief 里的那一个动作。

约束：
- 只输出一条首帧提示词，不要视频提示词、不要解释
- 结构：外观 + 场景 + 起始姿态 + 光线/风格
- 若锁形象：外观写「保持与设定图相同的外貌与服装」，不复述 brief 里的主体句
- 若不锁形象：外观锁定句从 brief「主体」来，逐字
- 场景从 brief「场景」来，并写清空间关系：下一步要碰到的东西，必须在运动路径上（正前方 / 手边 / 将要走的方向）。不要写「旁边」「周围」「脚边」这种可以随便摆的位置
- 起始姿态是动作开始那一瞬：尚未踏入、尚未伸手、尚未推门。不要已经发生的结果（水花、迈完的步、已经握住的物体）
- 人的朝向对着将要去的方向
- 景别必须能看见这次动作的交互点（踩水要看见脚和积水；拿手要看见手和物体）
- 运动方向留空位（人要往右走，右边要有路）
- 光线写主光从哪来、软硬、环境光颜色，不要只写「电影感」
- 背景要有可辨认的层次，不要只有人贴在一块虚化色斑上
- 不要写运镜、不要写还没发生的动作
- 时长、比例不写进提示词
```

## 出图后检查

不过就重出首帧，不进图生视频。

逻辑：

- 要碰到的东西在将要走的那条线上
- 朝向对着将要去的方向
- 画面是静止的：没有已经溅起的水、已经迈完的步、已经伸出的手

画质：

- 100% 放大：脸、手、服装边缘清楚，不糊、不融、没有多余手指
- 主光方向能看出来，主体和背景能分开
- 有前景 / 中景 / 背景，运动方向留得出空位
- 景别能看见这次动作（走路要看见脚和路，不要只有胸像）
- 分辨率不低于成片（1080p 成片，首帧至少同级）

## 出片后检查

能用：动作完整、首帧主体还在。
能留：再过下面几条。过「能留」才出成片分辨率。

- 主动作完整，接触点物理合理（脚沾地、水从踩到的地方溅）
- 脸和衣服不漂、不融化
- 画幅边缘不扭曲
- 没有莫名切镜、主体消失、出字
