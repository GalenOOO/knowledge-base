# Agent Skill 介绍

## 什么是 Agent Skill？

Agent Skill 是一种轻量级、开放式的模块化能力扩展包，用于增强 AI 智能体（Agent）在特定领域的表现。它将专业知识、工作流程和操作规范封装成可复用的"技能包"，让 AI Agent 能够按需加载并执行特定任务。

简单来说：**Skill = 一个结构化的指令包，告诉 AI "遇到某种场景时，应该怎么做"。**

## 核心特点

| 特点 | 说明 |
|------|------|
| **简单开放** | 使用纯文本格式（Markdown + YAML），无需复杂配置或专有工具 |
| **一次编写，到处使用** | 同一 Skill 可在 Claude Code、Cursor、Copilot、Codex 等 40+ 主流 AI 工具中使用 |
| **渐进式披露** | Agent 只在需要时加载相关技能，有效管理上下文窗口，避免信息过载 |
| **自文档化** | SKILL.md 文件本身就是文档，易于审计、理解和改进 |

## Skill 的文件结构

一个 Skill 的核心是一个包含 `SKILL.md` 文件的目录，标准结构如下：

```
my-skill/
├── SKILL.md          # 核心指令文件（必需）
├── references/       # 参考文档（可选）
└── scripts/          # 脚本工具（可选）
```

### SKILL.md 格式

```markdown
---
name: your-skill-name
description: 简要描述该 Skill 的功能和触发场景
---

# Skill 名称

## 功能说明
详细的分步操作指导...

## 使用示例
具体应用场景...

## 约束条件
必须遵守的规则...
```

YAML frontmatter 中必填字段只有两个：`name` 和 `description`。

## Skill vs Prompt vs Rules

| 概念 | 职责 | 比喻 |
|------|------|------|
| **Rules** | 管约束——"不能做什么" | 做人的底线 |
| **Skills** | 管能力——"怎么做才好" | 做事的方法 |
| **Prompt** | 一次性对话指令 | 临时的口头交代 |

## 工作流程

1. **启动扫描**：Agent 启动时，只读取所有 Skill 的元数据（名称 + 简短描述），不加载完整内容
2. **意图匹配**：当用户发出请求，Agent 判断是否需要调用某个 Skill
3. **按需注入**：只有当 Skill 被激活时，完整的 SKILL.md 才会被注入到对话上下文
4. **工具执行**：Skill 声明的工具权限被预先批准，自动执行

## 典型使用场景

- **领域专业知识**：将法律审查流程、数据分析管道等专业领域知识打包成可复用的技能
- **新能力扩展**：赋予 Agent 新能力，如创建演示文稿、构建 MCP 服务器、分析复杂数据集
- **可重复工作流**：将多步骤任务转化为一致且可审计的工作流程
- **组织知识管理**：将团队专业知识以可移植、版本控制的方式保存和共享

## 安装范围

| 范围 | 路径 | 用途 |
|------|------|------|
| **项目级**（默认） | `./<agent>/skills/` | 随项目提交，团队共享 |
| **全局级**（-g） | `~/<agent>/skills/` | 跨项目复用 |

## 安装方式

| 方式 | 说明 |
|------|------|
| **Symlink（推荐）** | 创建符号链接，单一数据源，更新一次全 Agent 同步 |
| **Copy** | 每个 Agent 拥有独立副本，互不干扰，但更新需逐个操作 |

## 安全注意事项

- 优先选择 **1K+ 安装量**、**官方来源**（vercel-labs、anthropics、microsoft）或 **GitHub 100+ Stars** 的 Skill
- 警惕读写本地文件系统、执行 Shell 命令的 Skill，安装前务必审查内容
- Skills 不是装越多越好，每个 Skill 都会占用 Agent 的上下文空间，按项目按需安装
