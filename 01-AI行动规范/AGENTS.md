# AGENTS.md

<一句话项目定位：项目类型 + 技术栈 + 用途>。本文件是 AI 代理接手任务前的入口。

## 启动协议

接到任何任务前，按顺序读取：

1. [`CONTEXT.md`](./CONTEXT.md) —— 项目上下文、目录结构、写作约定、当前进度（必读）
2. 若要改某模块代码，先读该模块**已存在的相关代码与文档**，保持风格一致
3. 若任务需要方法论支持，按需读 [`docs/`](./docs/) 下相关文档

## 必备命令

- `pnpm install` —— 安装依赖
- `pnpm dev` —— 本地开发
- `pnpm test` —— 跑测试（必须全过才算完成）
- `pnpm lint` —— 代码检查

## 目录导航

| 路径 | 内容 |
|------|------|
| `CONTEXT.md` | 项目上下文（必读） |
| `src/` | 源码 |
| `tests/` | 测试用例 |
| `docs/` | 架构文档与开发指南 |
| `<地雷目录>` | 自动生成 / 第三方 / 禁止手改 |

## 边界

**必做**
- 每次提交前跑 `pnpm test` 和 `pnpm lint`
- commit 信息用 Conventional Commits（`feat:` / `fix:` / `docs:` / `chore:`）
- 中文写作，代码与术语保留原文

**先问**
- 新建子目录或调整目录结构
- 增加/升级依赖包
- 修改核心配置文件（如 `next.config.js`、CI 配置、schema 文件）
- 引入新的编码约定或工具链

**永不做**
- 直接推送到 `main` / `master` 分支（必须走 PR）
- 提交 `.env` 或任何含密钥的文件
- 修改自动生成的目录（如 `src/generated/`、`dist/`）
- 删除或清空 `CONTEXT.md` 的"当前进度"段
